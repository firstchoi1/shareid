# 本地数据库说明

## 启动

```bash
docker compose -f docker-compose.db.yml up -d
```

## 查看状态

```bash
docker compose -f docker-compose.db.yml ps
docker logs --tail 50 shareid-postgres-local
```

## 连接信息

- Host: `127.0.0.1`
- Port: `55432`
- Database: `shareid`
- User: `shareid_user`
- Password: `shareid_local_password`

## 本地 DATABASE_URL

```env
DATABASE_URL=postgresql://shareid_user:shareid_local_password@127.0.0.1:55432/shareid
```

## 进入 psql

```bash
docker exec -it shareid-postgres-local psql -U shareid_user -d shareid
```

## 停止

```bash
docker compose -f docker-compose.db.yml down
```

## 清空重建数据库

```bash
docker compose -f docker-compose.db.yml down -v
docker compose -f docker-compose.db.yml up -d
```

## 迁移到服务器

本地验证好表结构后，服务器可复用同一套 SQL：

- `db/init/001_schema.sql`
- `db/init/002_seed_sites.sql`
